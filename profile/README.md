## `> whoami`

ExoDuck is a cybersecurity-focused organization exploring digital security, security research, and useful automation. We build tools and share projects with an emphasis on learning, responsible research, and practical security.

Discord bots are part of our toolkit—not the whole mission.

## `> areas_of_interest`

- **Cybersecurity** — security concepts, defensive practices, and research
- **Automation** — tools that make security-related workflows more useful
- **Discord bots** — bot projects and integrations
- **Open source** — learning, collaboration, and sharing knowledge
